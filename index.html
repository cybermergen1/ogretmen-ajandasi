    İşaretleyici:
    + Yaptı - Yapmadı ± Eksik G Gelmedi R Raporlu K Kitap Yok D Defter Yok
    Önce yukarıdan işaretleyiciyi seç (Okuma / Katıldı / Bozdu), sonra hücreye tıkla: işaret konur, tekrar tıklayınca kalkar. Bir öğrencide birden fazla işaret olabilir  ·  Klavye: o k b (aç/kapat), n / sağ tık / uzun bas = öğrenciye not, Sil = temizle, ok tuşları = gezin  ·  Sütun başlığındaki ✓ seçili işareti tüm öğrencilere koyar  ·  B toplamı 2 ve üzeri uyarı rengiyle görünür  ·  Köşesi işaretli hücrede not var
    Tıkla: boş → + → - → ± → boş  ·  Çift tıkla / uzun bas / sağ tık: tüm durumlar  ·  Klavye: + - e(±) g r k d, Sil = temizle, ok tuşları = gezin  ·  Sütun başlığındaki ✓ boşların hepsini + yapar

    ⚙ Puan & İşaret Ayarları (bu sınıf)

    Faaliyet puanı (0–100) = Okuma ağırlığı × okuma oranı + Katılım ağırlığı × katılım oranı − bozma başına ceza × bozma sayısı + özel işaretlerin etkisi. Oranlar, seçili dönemdeki sütun sayısına göre hesaplanır.

    Özel işaretler (en fazla 5)
    Sembol · ad · renk · puana etkisi (her işaret için ±puan; 0 = puanı etkilemez)
